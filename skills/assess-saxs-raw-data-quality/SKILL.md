# 评估一批 SAXS 原始帧的质量（拟合之前、独立于任何拟合）

## 什么时候用

- 用户拿到一批新数据，问"这批数据好不好 / 能不能用 / 哪个样品扔了"。
- 某个样品**扣减后低 q 上翘**，有人（导师、审稿人、自己）说"像蛋白相互作用/聚集"——**先归因，再下结论**。
- 拟合结果不对劲（Rg 随浓度乱漂、IFT 的 Dmax 跑到搜索域顶、Kratky 高 q 翘），要回查是数据问题还是模型问题。
- 上机前设计采集方案：需要几个 buffer、放在哪、要不要同一根毛细管夹心。

## 不做什么

- **不做任何拟合**：不碰 Guinier/IFT/重建。这些是别的 skill 的事；本 skill 只判"原始帧能不能支撑那些拟合"。
- 不替代端到端流水线（`run-a-tube-saxs-pipeline-end-to-end` / `run-a-sec-saxs-pipeline-end-to-end`）：流水线出结果，本 skill 判**结果能不能信、以及在哪个 q 范围上才可信**。
- 不把"上翘"直接翻译成"相互作用"。单条曲线的低 q 上翘**不是** A2 或相互作用的证据（见 Step 3 与 `references/upturn-attribution-protocol.md`）。

## 结论长这样（每条都要能被反驳）

> 样品 X：**可用 / 勉强可用 / 不可用**。理由 = 数字 + 判据：
> 低 q 对比度 18.6%（>2%）、20 帧 run 内漂移 0.4%、离群帧 0、单帧 SNR≥2 到 q=0.248；
> 但**背景 `ddh2o_0020` 自身在 run 内漂 7.5%**，建议整条剔除后再扣减。
> **排除**了什么、**还剩**什么、下一步做哪个实验——缺一不可。

判据阈值集中在 `scripts/raw-qc-frames.py` 的 `RULES`（可逐条辩论），不要口头给印象分。

## 机理（四条，先想清楚再动手）

1. **未扣减的帧上，低 q 由寄生散射主导。** 管/毛细管 + beamstop 尾巴给出近似 **q⁻⁴** 的强背景，
   样品与背景里都有（实测同一帧从 q=0.0064 到 q=0.0162 掉 8 倍：1380→163）。扣减才消掉它。
   → **低 q 的形状只能在扣减后的差谱上判**；在原始帧上算"上翘/聚集"会全员报警。
2. **run 是基本单位**（一次连续曝光，同一位置/浓度，通常 20 帧）。"run 内漂移"（辐照损伤/沉降/进样/
   束流）和"run 间电平差"（两条背景 run 本身不同）是两件事：**前者剔帧，后者按 run 分别定标或整条弃用**。
3. **透射归一化后有残差。** 单帧水平仍剩几个 % 起伏，表现为"帧间起伏 ÷ RAW 报的 σ"= 3-5 倍。
   这个比值量的是**归一化残差，不是"误差估计对不对"**；只有它异常大（>10）才回头查 error propagation。
4. **对比度决定天花板。** 低 q 对比度 <1% 时，扣减曲线是两个大数相减的小差，背景 1% 抖动就伪装成形状。
   最稀那管（对比度 3%）实测扣减后上翘 5.5、单帧 SNR≥2 只到 q=0.095 Å⁻¹ —— 低 q 已经不可信。

## Step 0 — 先量几何，别先看曲线

同一套代码在不同线站/探测器上不可移植的只有几何。开跑前先确认三件事，用 `scripts/inspect-lowq-image.py` 一次印出：

1. **中心对不对**：RAW 读 Pilatus 时返回的数组相对 `.cfg` 的 `Ycenter` **上下翻转**，
   图像里的束斑行号是 `n_rows-1-Ycenter`。验证法：手算径向平均必须复现 RAW 自己的 1D 形状
   （正确中心 `RMS(log)≈0.02`，用错中心 `≈0.22`）。中心错了，后面所有 q↔r 判断全废。
2. **beamstop 挡到哪、那段 q 是多少**：本机 BL19U2（Pilatus 2M / D=2680 mm / λ=1.033 Å）实测
   **r≤12 px 全遮挡、r=16 px 只有 38% 的环未遮挡、r≈25 px 到 75%**（完全开放≈90%）。
   换算：**q≈0.0064 在 r≈17 px，q≈0.010 在 r≈26 px**。
   → 结论：**低 q 判断（上翘、Guinier、IFT）从 `--qmin 0.010` 起**，第一批点坐在光束挡边缘，
   带着一段扣不掉的光晕（实测占稀样品低 q 上翘的 **75-80%**）。
3. **q 上界**：每个样品的可用 q 上限由**单帧** SNR≥2 决定（多帧平均只把它按 √N 往外推）。
   稀样品单帧只到 q=0.095-0.13，报告里必须写明。

细节与全部实测数字：`references/bl19u2-geometry-and-mask.md`。

## Step 1 — 逐帧 QC（`scripts/raw-qc-frames.py`）

一个目录一个样品（样品帧 + 夹着它的 control 帧），按 run（`<name>_<NNNN>_00001.tif` 的前两段）分组，输出：

| 维度 | 指标 | 怎么算 | 判据（写在 RULES 里） |
|---|---|---|---|
| 信号 | 低 q 对比度 | `mean(I_diff[q<0.02]) / mean(I_control[q<0.02])`（分母是**背景**电平，报告要写明） | <0.5% 直接不可用；<2% 报警 |
| 信号 | 单帧信噪上界 | 由平均曲线 `SNR(q)=I/σ`，单帧 `≈SNR/√N`，取 SNR=2 的 q | 单帧 <0.15 Å⁻¹ 报警（该浓度 q 范围不够） |
| 稳定性 | run 内电平漂移 | 该 run 内 `i_lo` 线性拟合的 `斜率×(N−1)/均值`（**不用末帧−首帧**） | >10% 报警（辐照损伤/沉降） |
| 稳定性 | 帧间起伏 | 同 run 内 `i_lo` 的相对标准差 | >5% 报警（样品/背景分别） |
| 稳定性 | 离群帧 | `|i/本 run 中位数−1|`：低 q 用 15%、**q=0.2 单点用 10%** | >20% 帧报警；**名单必须落 `qc.json`** |
| 稳定性 | 相邻帧最大跳变 | run 内 `max|i_02(k)/i_02(k−1)−1|` | >15% 报警（气泡/进样/束流事件） |
| 背景 | control 缩放因子 | 高 q 无粒子窗（0.30–0.44 Å⁻¹）的 `mean(I_sample/I_control)` | \|f−1\|>5% 报警（通量/位置不匹配） |
| 背景 | control run 间电平差 | 各 control run `i_lo` 中位数 `max/min−1` | >5% 报警（单个缩放因子消不掉） |
| 误差 | 误差诚实度 | **单个 q 点**上 `std_over_frames(I) / mean(σ)` | >4 报警（归一化残差占主导）；>10 才回头查 error propagation |
| 形状 | 扣减后低 q 上翘 | `I_diff(q₁)/I_diff(2 q₁)`，q₁ 取最低 q 的**第 2 个点** | >1.05 可疑、>1.2 判上翘 → 转 Step 3，**不要直接下结论** |

产物：`<root>/_rawqc/{raw_quality.md, raw_quality.csv}`、每样品 `qc.json` + `frame_qc.csv`；
`scripts/plot-frame-stability.py` 出逐帧稳定性图（每格一条"该 run 中位数归一"的曲线，直接拿去讨论）。

## Step 2 — 看扣减后的形状（不看这一眼别谈 Rg）

- 曲线从 q_min 到 q≈1/Rg 是否**单调、平滑**；低 q 定量比 `I(q1)/I(q2)` 在 1.0±0.2 才算"平"。
- **Kratky `q²I`**：有峰且回零=紧凑折叠；高 q 一直抬=柔性/无序/背景没扣干净。
- 判据数字（本机 11 个样品实测）：紧凑的 20 kDa 蛋白 `I(0)/I(0.2)≈17-33`，
  大颗粒/聚集体会到 **60-5500**；Kratky 峰位从 q≈0.06-0.08（小蛋白）挪到 0.02-0.05（大颗粒）。
  所以"Kratky 峰位 + I(0)/I(0.2)"是一条不依赖拟合的快速分型。

## Step 3 — 低 q 上翘归因（三道检验，按这个顺序做）

**先问"它随浓度怎么变"。** 相互作用/聚集的信号强度随浓度上升（吸引 → S(q→0)>1，或聚集体的 I(0)），
**稀释必然让它变小**；而固定量级的背景/寄生残留，随稀释只有**相对**变大的份。
本机实测（同一蛋白 2 倍稀释序列 6 个点，浓度跨 32 倍）：
`I(0.0064)/I(0.0128) = 1.04 / 1.09 / 3.08 / 6.33 / 9.28 / 6.03`，过量计数 `+2.7/+4.4/+50/+94/+95/+26`。
**越稀越翘、且绝对量级不随浓度走 ⇒ 与"相互作用"相反。**

然后三道检验（脚本一一对应）：

1. **空白 − 空白**（`scripts/attribute-lowq-upturn.py`）：把两根 buffer run 用**同一条流程**相减，
   里面一个蛋白都没有。它的 `dI` 就是背景能造出来的上限。本机实测空白-空白 `|dI| ≤ 12 counts`；
   若样品-空白的 `dI` 与之同量级 → 上翘是背景；大 4-8 倍（如 A5-05-4/-5 的 +94/+95）→ **有真东西**，进第 2 步。
2. **背景自身的可复现性**（`scripts/blank-reproducibility.py`）：不缩放地看比值 `r(q)=A/B` 从定标窗
   到最低 q 变了多少（`shape = r(q1)/r(win)`）。流水线只能扣一个**常数**，`(shape-1)×(q1 处电平)`
   会原封不动留在曲线上。本机实测：**空白-空白 shape ≤1.2%（≈12 counts）**，
   样品-空白 shape 2.7-9.6%（+33…+126 counts）→ 超出的部分是样品带的，不是"空白太吵"。
3. **2D 差分图**（`scripts/inspect-lowq-image.py`）：把样品帧与 control 帧各平均、缩放后相减。
   - **铺满视场的各向同性光晕** = 真散射（最浓的 A5-05-1 就是这样，1D 上翘只有 1.04）；
   - **紧贴 beamstop 的一圈窄亮环 + 其余是平的噪声** = 光束挡边缘/寄生散射（最稀的 A5-05-5 就是这样，
     1D 上翘却有 9.3）——**这种"上翘"换任何扣减都去不掉，只能靠 `--qmin` 砍掉。**
   再配一个可选的量化：裁剪 `--qmin 0.010` 后上翘掉多少（实测 6.3/9.3/6.0 → 3.5/4.4/3.8）。

**三步之后的结论只有两种写法**（别写成第三种含糊话）：

- 上翘 = 背景/边缘假信号 → 给 q_min 截断值，并说明这解释了哪些"低 q 不服从单一 Guinier 定律"。
- 上翘 = 真散射 → 只能说"存在一个低 q 过量成分"；**要判它是相互作用还是聚集体，必须另做实验**：
  5-8 个浓度、同一根毛细管、buffer→样品→buffer 夹心、每浓度重复 2-3 次 → 画 **I(0)/c vs c 取 A2**
  （或对 S(q) 做 Ornstein-Zernike 拟合）。单条曲线的上翘在审稿会上站不住。

## Step 4 — 结论与交接

- 报告必须写成**完整陈述**：结论 + 数字 + 判据 + **排除了什么 + 还剩什么 + 下一步**。
- 交给下游时把 q_min 一起交出去（流水线 `run-raw-tube-pipeline-end-to-end --qmin 0.010`），
  否则 Guinier/IFT 还会去拟合那段带光晕的点。
- 建议剔除的帧/run 要**点名到文件名**（脚本已把 `worst_frames_midq` 与各 run 电平写进 `qc.json`）。

## 坑（都是实跑踩出来的）

- **低 q 判据看不见样品侧的异常帧**：低 q 被与背景共模的寄生散射主宰，样品 run 里的一次束流/进样
  波动要**在 q=0.2 上判**（本机 11 个样品 q=0.2 的帧间跳变只有 2-3%，而低 q 上能看到 10-25% 的坑）。
  两套判据都要跑，结论按 q=0.2 的那套。
- **样品排在同一个 run 里，背景却分成两个 run**：于是"背景的 run 间差异"（本机 ≤1.7% 电平差，
  但个别 run 内部漂 7.4-7.5%）会直接变成低 q 系统误差。报告里要点名漂移的那条 run。
- **`Concentration_mg/ml` 常常是空的**：所以对比度、I(0)/c 这些要走"不需要浓度的量"（对比度、Vc-MW、
  I(0)/I(0.2)），别假装有浓度。
- **不要把"扣减后低 q 有强度"当成低 q 信号可信**：那可能全是光晕；先做 Step 3 的 2D 检验。
- **背景电平绝对值全天稳（本机 328±3 counts，1%）不代表低 q 形状也可复现**：形状的可复现性要单独测
  （Step 3 第 2 步），本机是 ≤1.2%。
- 脚本用 **RAW 自带的解释器**跑（`/Applications/BioXTASRAW/bin/python`，含 pyFAI/numba），
  不要在 RAW 源码目录里跑（`sascalc_exts` 会被遮蔽）。

## 脚本（`scripts/`，全部 `--help` 里有默认值+单位）

| 脚本 | 干什么 |
|---|---|
| `raw-qc-frames.py <root> --cfg <day>.cfg [--qmin Q]` | 逐帧质量表 + 结论（`_rawqc/raw_quality.{md,csv}`、每样品 `qc.json`） |
| `plot-frame-stability.py <root>` | 逐帧稳定性图（每样品一格，蓝=样品/红=control/绿=透射） |
| `attribute-lowq-upturn.py <root> --cfg …` | 上翘归因第 1 步：样品-全部空白 vs 空白-空白 vs 逐个空白 |
| `blank-reproducibility.py <root> --cfg …` | 上翘归因第 2 步：比值 `r(q)` 的形状失配 → 残留 counts 上限 |
| `inspect-lowq-image.py <sample-dir> --cfg …` | 上翘归因第 3 步：2D 差分图 + 方位角判据 + 中心校验 + q↔r 换算 |
| `qc_common.py` | 共用件（settings/run 分组/缩放扣减/中心与 q↔r/掩膜径向剖面），不单独运行 |

参考：`references/bl19u2-geometry-and-mask.md`（几何与掩膜的实测数字）、
`references/upturn-attribution-protocol.md`（归因协议 + 本机标定值 + 下一步实验设计）。
