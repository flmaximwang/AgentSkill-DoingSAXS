# 几何与掩膜：低 q 到底从哪个 q 开始才可信

本文件记录 **BL19U2 / Pilatus 2M / D=2680 mm / λ=1.0332 Å**（2026-10-01 那批管式数据）的实测几何。
换线站/探测器/距离时，用同一套方法重测（最后一节），不要照搬数字。

## 1. 中心：RAW 读进来是上下翻转的

`.cfg` 里 `Xcenter=715.32`、`Ycenter=941.97`，但图像数组（shape=(1679, 1475)）里束斑在**第 748 行**附近，
不是 942。原因：RAW 的 Pilatus 读取相对 `.cfg` 的 `Ycenter` **flip 了 y**。图像坐标应为

```
x_img = Xcenter                        # 715.3  (列，与 argmax 的 713 一致)
y_img = n_rows - 1 - Ycenter           # 1679-1-942.0 = 736.0  (行)
```

**验证法（任何线站都通用）**：对同一张图，手算径向平均（按掩膜排除遮挡像素），
与 RAW 自己的 1D `I(q)` 比形状（都归一化到窗口第一点）。实测：

| 用哪个中心 | RMS(log) | 相关系数 |
|---|---|---|
| `(715.3, 736.0)` 翻转后 | **0.025** | 0.85 |
| `(715.3, 942.0)` 直接用 cfg | 0.221 | 0.23 |

脚本 `inspect-lowq-image.py` 每次运行都会印这个校验（`centre check vs RAW 1D`）。

⚠️ 手算径向平均时**必须排除掩膜像素**（模块缝 + beamstop）：不排除会把缝的强度混进来，
RMS 从 0.025 劣化到 0.048、相关系数掉到 0.10（同一个正确中心）。

## 2. beamstop 挡到哪（掩膜径向剖面）

`Masks['BeamStopMask'][0]` 的径向平均（未遮挡比例；完全开放≈0.90，剩下的 10% 是模块缝）：

| r (px) | 未遮挡比例 | q (Å⁻¹) |
|---|---|---|
| 0-12 | 0.000 | ≤0.0047 |
| 14 | 0.016 | 0.0055 |
| 16 | 0.381 | 0.0062 |
| 18 | 0.610 | 0.0070 |
| 20 | 0.654 | 0.0078 |
| 25 | ~0.75 | 0.0099 |
| 30 | 0.791 | 0.0117 |
| 51 | ~0.88 | 0.0200 |

q↔r 换算（与 RAW 一致）：`q = 4π sin(atan(r·px_mm/D)/2)/λ`，px_mm=0.172 mm、D=2680 mm、λ=1.0332 Å。

**结论：`q=0.0064`（第一个数据点）落在 r≈17 px —— 那里只有 38% 的环可用，正好坐在光束挡边缘。**
这段区域带着一段**扣不掉的边缘光晕**（束流挡边缘的寄生散射）：实测把 `q<0.010` 砍掉后，
稀样品 A5-05-4/-5/-6 的首点强度从 130/124/41 掉到 37/26/12 counts，低 q 上翘从
6.33/9.28/6.03 掉到 3.46/4.37/3.83 —— **即 75-80% 的"上翘"只来自那一个点**。

所以在喂给 Guinier / IFT / P(r) 之前，先把 q_min 抬到 beamstop 之外：

```
run-raw-tube-pipeline.py … --qmin 0.010        # 0.010 = r≈26 px，本机经验值
raw-qc-frames.py … --qmin 0.010
```

## 3. 换一个线站/探测器怎么重测

1. 用 `qc_common.unmasked_fraction_by_radius(s)` 印掩膜径向剖面 → 读出"未遮挡比例 ≥0.75"的半径 r75；
2. `qc_common.r_of_q(q, s)` / `q_of_r(r, s)` 把 r75 换成 q → 这就是该站点的默认 q_min；
3. 用 `inspect-lowq-image.py` 的 `centre check` 确认中心（不要相信 `.cfg` 里那个值）；
4. 把这三个数字（px_mm、D、λ、q_min）写进本次实验的 README，别只记在脑子里。

## 4. 这条几何经验的适用边界

- 只对"样品与背景都测过、要扣减"的数据重要；**SEC-SAXS 逐帧同样适用**（洗脱峰的每一帧都在同一几何下）。
- 直径更大的样品池/毛细管、或换用真空管/flow cell 时，**寄生散射的形状与强度都会变**，
  Step 3 第 2 步（空白-空白可复现性）必须重新测一次，不要沿用旧数字。
- 中心偏 1-2 px 对 q>0.05 的形状影响可忽略，但对 r<30 px 的低 q 环带影响很大 —— 低 q 结论对中心误差最敏感。
