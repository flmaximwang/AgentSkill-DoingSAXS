# 低 q 上翘归因协议（本机标定值 + 下一步实验设计）

## 0. 先立规矩：单条曲线的上翘不是相互作用的证据

低 q 上翘至少有四种来源，它们的 1D 形状可以长得一样：

| 来源 | 随浓度怎么变 | 形状线索 | 怎么排除 |
|---|---|---|---|
| 吸引相互作用（S(q→0)>1） | 信号 ∝ c（强度）**随稀释变小** | 浅，Ornstein-Zernike 型（远处趋 q⁻²） | 浓度序列 → A2 / OZ 拟合 |
| 微量聚集/大颗粒 | 绝对 I(0) ∝ c，也随稀释变小 | 陡，常带 q⁻³~q⁻⁴ 的 Porod 尾巴 | SEC 或离心前后对比 |
| **背景/寄生散射残留** | 固定量级（与 c 无关）→ **随稀释相对变大** | 由背景形状决定；紧贴 beamstop | 空白-空白 + 2D 差分 + q_min 截断 |
| beamstop 边缘光晕 | 同上，固定量级 | 只占最低 1-3 个点，2D 上是窄亮环 | 砍掉 q<q_min 后消失多少 |

**第一条判据永远是浓度标度律，不是形状**：稀释让真正的相互作用/聚集信号变小，
让固定的背景残留相对变大。方向反了，就先怀疑背景。

## 1. 本机标定值（2026-10-01 管式批次，A5-05-1…6 = 同一蛋白 2 倍稀释序列，浓度跨 32 倍）

（1D 值：`I(q1)/I(2q1)`，q1=0.0064；过量 = `I(q1)-I(2q1)` counts，未做 q_min 截断）

| 样品 | I(0) (稀释序) | 上翘比 | 过量 counts | 扣减后形状 n | 首点 2D 差分 |
|---|---|---|---|---|---|
| A5-05-1 | 65.5 | **1.04** | +2.7 | 0.1 | 铺满视场的各向同性光晕 |
| A5-05-2 | 35.8 | 1.09 | +4.4 | 0.2 | — |
| A5-05-3 | 20.2 | 3.08 | +50 | 1.3 | — |
| A5-05-4 | 10.9 | 6.33 | +94 | 2.3 | — |
| A5-05-5 | 5.3 | **9.28** | +95 | 2.8 | 平的噪声 + **紧贴 beamstop 的窄亮环** |
| A5-05-6 | 2.4 | 6.03 | +26 | 2.4 | — |

**越稀越翘 + 绝对量级不随浓度走 → 与"相互作用"相反。** 若真按 A2 走（∝c²），
从 A5-05-1 到 -6 该掉 1000 倍；实测反着涨。

背景能造出多少（三道检验的实测标定）：

| 检验 | 做法 | 实测值 |
|---|---|---|
| 空白 − 空白 | 两根 buffer run 同流程相减（无蛋白） | `|dI| ≤ 12 counts`（pb7 与 ddh2o 各 4 对） |
| 背景形状失配 | 不缩放地看 `shape=r(q1)/r(win)` | 空白-空白 ≤**1.012**；样品-空白 1.027-1.096 |
| 边缘点贡献 | `--qmin 0.010` 前后比 | 上翘 6.3/9.3/6.0 → 3.5/4.4/3.8（首点强度降 75-79%） |

判读模板（照抄进报告）：

> 样品-空白给 +111 counts，而空白-空白只能给 ±12 counts，背景形状失配 ≤1.2% → 
> 超出部分（约 4-8 倍）不是"背景太吵"；
> 但其中 75-80% 集中在 r≈17 px 的一个点上（beamstop 边缘，仅 38% 环可用），
> 砍掉 q<0.010 后剩 25-30 counts 且不随浓度变化（0/3/64/115/106/31 counts 跨 32 倍稀释）。
> **结论：上翘真实存在，但既不是浓度驱动的相互作用信号，也没能在 2D 上看到铺开的光晕；
> 最可能是背景/寄生残留，或少量、逐管不等的聚集。用这批数据分不开这两者。**

## 2. 归因流程（脚本顺序）

```
raw-qc-frames.py            # 出对比度/漂移/离群/上翘比 → 决定要不要做归因
attribute-lowq-upturn.py    # ① 样品-全部空白 vs 空白-空白 vs 逐个空白（换空白结论稳不稳）
blank-reproducibility.py    # ② shape = r(q1)/r(win)  → (shape-1)×电平 = 背景残留上限
inspect-lowq-image.py       # ③ 2D 差分：各向同性光晕 还是 beamstop 窄亮环（+ 中心校验）
```

三条都要做，**不要跳到②或③就下结论**：
① 告诉你换一个空白结论会不会变（本机实测不变：A5-05-5 用 ddh2o_0020 或 0022 都得 9.07/9.74）；
② 把"背景能造多少"变成一个 counts 数；③ 告诉你那部分多余强度在探测器上长什么样。

## 3. 要真给"相互作用"下结论，得做实验（不是再分析）

1. **同一根毛细管、同一位置**，`buffer → 样品 → buffer` 夹心测；每个浓度重复 2-3 次。
   这样"样品管 vs 空白管"这一项系统误差可以被直接测出来（本机的空白-空白只覆盖了"空白管 vs 空白管"）。
2. **浓度序列 5-8 个点**（覆盖 10 倍以上浓度范围），每个点独立配样、独立上样。
3. 分析走两条路之一：
   - `I(0)/c` 对 `c` 作图，斜率 ∝ 第二维里系数 A2（负=吸引，正=排斥）；
   - 对低 q 的 S(q) 做 Ornstein-Zernike 拟合 `I(q)=I(0)/(1+q²ξ²)`，看 ξ 随浓度怎么变。
4. 如果只是想排除假信号：把最低 q 的 3-5 个点砍掉重拟合，**报告里写明 q_min** —— 这是最省事的合规做法。

## 4. 别的坑

- **别用"扣减后低 q 有强度"证明低 q 数据可信**：那可能 100% 是光晕（本机稀样品的首点就是这样）。
- **过量的"形状"不能单独当判据**：本机稀样品的过量形状 n≈2.2-2.8（看着像 OZ 的 q⁻²），
  但它随稀释变大 —— 形状像 ≠ 机制对。
- **空白 run 内部漂移会被整段平均掉，进而歪掉低 q**：本机 `ddh2o_0020`（run 内漂 7.5%）、
  `pb7_0011`（−7.4%、帧间起伏 6.8%）都属此类；报告要点名，建议整条剔除或按 run 分别定标。
- **同一批数据里背景电平全天稳定（328±3 counts）不等于形状可复现**：形状要按 ② 单独测。
- 结论里要写清**还剩什么**：写成"数据不足以区分 A 与 B，需做实验 C"是合格的结论；
  写成"像相互作用"是不合格的。
