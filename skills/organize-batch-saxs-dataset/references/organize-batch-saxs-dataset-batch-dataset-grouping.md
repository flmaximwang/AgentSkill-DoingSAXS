# batch 数据归类的深度笔记

## 1. 一个真实批次的形状（可作为对照基线）

BL19U2 batch 模式一次上机 23 个 series：11 个样品 + 12 个背景，每个 series 20 帧。

| 项 | 值 |
|---|---|
| 每帧文件 | `.tif` + `.txt` |
| 每 series 额外 | `_00001.log` + `<series>.Intensity` |
| 每 series 文件数 | 20 + 20 + 1 + 1 = **42** |
| 源目录文件总数 | 23 × 42 = **966**，+3 个 RAW/GNOM 衍生产物 = 969 |
| 落盘后总数 | 样品各自 42，背景进两个文件夹 → **1347** |

排列（run 号即测量顺序）：

```
pb7_0001  BSA_0002  pb7_0003  877-apo-pb7_0004  pb7_0005  877-4zinc-pb7_0006
pb7_0007  5705_0008 pb7_0009  97df_0010         pb7_0011  ddh2o_0012
A5-05-1_0013  ddh2o_0014  A5-05-2_0015  ddh2o_0016  A5-05-3_0017  ddh2o_0018
A5-05-4_0019  ddh2o_0020  A5-05-5_0021  ddh2o_0022  A5-05-6_0023
```

两类背景各管一段：`pb7` 夹住 BSA / 877-apo / 877-4zinc / 5705 / 97df；`ddh2o` 夹住 A5-05-1…6。

## 2. 归类结果与"落单"背景的算法解释

每个样品拿"前一背景 + 后一背景"，于是：

- 4 个 pb7（0003/0005/0007/0009）+ 5 个 ddh2o（0014…0022）= **9 个背景进两个文件夹**；
- **3 个只进一个**：
  - `pb7_0001` —— 批次的第一个 series，前面没有样品；
  - `pb7_0011` —— 一侧是 `ddh2o_0012`（背景），到最近样品 `97df_0010` 距离 1、到 `A5-05-1_0013` 距离 2 → 只进 97df；
  - `ddh2o_0012` —— 对称的另一半，到 `A5-05-1` 距离 1、到 `97df` 距离 2 → 只进 A5-05-1。

**通则**：在两类背景的交接处，两侧各有一个背景"背离样品"，它们各自只进一个文件夹。所以"落单背景数"的正常值是 `2 × (背景种类数 − 1) + 首尾端点`，不是 0。报告里把算出来的距离写出来，用户才不会把它当漏放。

## 3. 恢复：静默合并已经发生了怎么办

症状：目标样品文件夹的条目数明显偏大，且里面混着**上一批实验**的文件（同名前缀、大小写不同，如新样品 `BSA` 混进旧实验的 `bsa`）。

1. 先枚举合并后的目录，按**计划里属于新样品的 series 前缀**筛出该搬走的文件：
   `ls <merged> | grep -E '^(<series_a>_|<series_b>_|…)[_.]'`——正则锚定 `^系列名[_.]` 是关键，不要用裸名字匹配。
2. 建好正确的目标文件夹，把这批文件 `os.replace` / `mv` 过去（**移动**，因为它们在原位是错放的副本，不是共享背景）。
3. 核对**旧目录的条目数回到合并前的值**（例：旧实验 `bsa` 恢复为 2003 条），并 grep 确认旧目录里再没有任何新样品的 series 前缀。
4. 再对全部落位文件做一次 sha256 与源目录比对。

## 5. 目标目录怎么定

用户可能先说了 A 目录、看到结果后改口 B。判断依据不是记忆，而是**数据本身**：

- batch 模式（一批样品各连拍约 20 帧、样品间夹背景）→ 属于 batch 归类，落 Tube-SAXS 这类目录；
- 连续洗脱（单个样品上千帧、有色谱图）→ 属于 SEC-SAXS。

若两边目录看起来被手工对调过（mtime 同一时段、旧实验文件夹整批换位），先 `find <base> -maxdepth 2 -type d` 看清全局，再决定搬什么——**先看现状，再动手**。
