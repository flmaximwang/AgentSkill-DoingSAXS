# 嵌入是两个靶子、两套坐标、两个分数——不是一个"叠上去看看"

一条高分辨模型要放进从头算重建里，得放进**两个不同的东西**：珠模型（DAMMIF/DAMMIN 的 dummy atom 模型，或 DAMAVER 平均/滤过后的共识模型）和电子云（DENSS 的 `.mrc`）。它们**不是同一个坐标系里的同一个物体**：各自只被自己的程序居中在各自的原点上，彼此的相对取向没有任何数据约束。所以"一次叠好、出一张图"这件事本身不成立——**两条分支各自做刚体叠合、各自报分**，混在一张图里就会得到"模型戳出珠球"的假象（本次实跑踩过，见 A1-4）。

还有一件更基本的事：**嵌入是刚体叠合（superposition），不是精修（refinement）**。它只回答"这个形状能不能摆进去、摆进去有多贴"，不回答"这个模型对不对"（那要 `fit-a-high-resolution-model-to-data` 的 CRYSOL/PDB2SAS 直接拟合），也不回答"这个重建本身可不可信"（那是 `evaluate-a-shape-reconstruction`）。

## R — 原文 (Reading)

> CIFSUP, is a program to superimpose one set of atomic coordinates onto another. These coordinates may be low-resolution bead models and/or high resolution NMR or x-ray crystal structures.
>
> 出处：源A CIFSUP 手册 · Introduction

> `--selection=` One of ALL (all atoms), BACKBONE (only the backbone/CA atoms), REGRID (convert both inputs to DAM) or SHELL (use only the outermost atoms); default: ALL
>
> `--method=` One of NSD, NCC, ICP or RMSD; default: ICP
>
> 出处：源A CIFSUP 手册 · Command-Line Arguments and Options

> Use CIFSUP to align a dummy atom model on a crystal structure, using the options to select the method that corresponds to slow mode in SUPCOMB and writing the output in PDB format:\
> `$ cifsup --method=nsd 6lyz.pdb ly01-1.pdb -o ly0r.pdb`\
> As above, but equivalent to fast mode:\
> `$ cifsup --method=nsd --selection=regrid 6lyz.pdb ly01-1.pdb -o ly0r.pdb`
>
> 出处：源A CIFSUP 手册 · Examples（CIFSUP as replacement of SUPCOMB）

> CIFSUP does not have any runtime output. If the output file is undefined, the transformed coordinates will be written to a (new) file path created from the basename of the MOVABLE argument plus r.cif.
>
> 出处：源A CIFSUP 手册 · Runtime Output

> Briefly, if two three-dimensional models are represented as a set of points, for every point in the first set (model 1), the minimum value among the distances between this point and all points in the second set (model 2) is found, and the same is done for the points in the second set. These distances are added and normalized against the average distances between the neighboring points for the two sets.\
> For ideally superimposed similar objects, NSD tends to 0; it exceeds 1 if the objects systematically differ from one another.
>
> 出处：源A SUPCOMB 手册 · Introduction

> The **fitmap** command performs rigid-body local optimization(s) to fit an atomic model or map into a map.
>
> Prior to local optimization, the fit model should be placed in a trial position relative to the reference map before fitting. Unless global search is used, this usually involves interactive manipulation …
>
> 出处：源A ChimeraX fitmap · Usage

> **resolution** *r* — Generate a density map from the coordinates of the specified atoms and perform map-in-map fitting instead of atoms-in-map fitting. Both types of fit values will still be reported. The map is generated by describing each atom as a Gaussian distribution of width proportional to *r* …
>
> If atoms are specified but this option is not given, ***atoms-in-map*** fitting will be performed: The average map value at fit atom positions is maximized.
>
> 出处：源A ChimeraX fitmap · Options

> Some values for the metrics can be shown as None, for example, if fitting an atomic model without specifying a resolution, the correlation will be None.
>

>
> 出处：源A ChimeraX fitmap · Global Search Options

## I — 骨架 (Interpretation)

**两条分支，两个分数，两种"看不出对错"的方式。**

### 分支 1：珠模型 → CIFSUP，分数 NSD

- 调用形状：`cifsup --method=NSD --selection=<SEL> -o <out> <珠模型> <原子模型>`（template=珠模型，movable=原子模型）。方向随便定，NSD 近似对称（实测同一次叠合正反两向 0.744407 / 0.744313），但**写清谁被移动**：输出的坐标是 movable 被搬到 template 坐标系里的结果。
- **`--selection=REGRID` 是默认口径**：官方把它定义为"等同于 SUPCOMB 的 fast mode"，而 SUPCOMB 的 fast 是方法学里的常规用法（`ALL` 对应 slow mode）。本次实跑四个选项的 NSD 相差很大（A5-05-1：REGRID 0.875 / BACKBONE 1.141 / ALL 2.202 / SHELL 2.202）——所以**报 NSD 必须同时报 selection**，否则这个数没有意义。
- **判读只有官方给的那一条刻度**：NSD→0 表示两个点集理想叠合，**>1 表示两者系统性地不同**。**不要**把 SUPDB/SUPALM 或 DAMAVER 内部 NSD 的阈值搬过来当"嵌入合格线"；本 skill 只做"报数 + 报用法"。
- 珠模型本身不唯一：同一个样品换一批 DAMMIF 随机模型，共识珠模型就换一个，NSD 跟着动（实测同一条 A5-05-1 曲线、两批各 3 个模型：NSD 0.744 vs 0.933）。**NSD 的位数（0.87 还是 0.93）不是样品差异，是珠模型系综差异。**

### 分支 2：电子云 → ChimeraX fitmap，分数 correlation / overlap

- 必须给 **`resolution R`**：不给就是 atoms-in-map 模式，只最大化"原子位置上的平均图值"，**correlation 一栏会是 None**（官方原文如此，不是 bug）。给了 `resolution` 才是 map-in-map，correlation / correlation-about-mean(cam) / overlap / average_map_value 一起出。
- 必须做 **global search**：fitmap 是**局部**优化器，结果取决于叠合开始前模型"恰好"在哪。用 `search 200 seed 42` + `logFits out.csv`，把 200 个随机初始位置的解列出来；**seed 固定**才可复现（官方要求先 `view initial` 再定 seed）。
- 报四个数（都从 CSV 里取）：`correlation`（绕零相关）、`correlation_about_mean`（cam，扣均值后更接近"像不像"）、`overlap`（尺度相关，换标度就变）、`average_map_value`。
- **resolution 取多少**：单个 DENSS 模型没有 FSC，读不出重建分辨率，所以**不要只跑一个 R**。跑一条阶梯（默认 10/15/20/25 Å）并报**姿态散布**——这才是这步的判据：
  - 实测 A5-05-1：0.8678(10 Å) / 0.8812(15 Å) / 0.8782(20 Å) / 0.8820(25 Å)；相关值几乎不随 R 变；
  - 而**姿态**变：相对最高分（25 Å）那个解，CA-RMSD 为 1.70 Å(10 Å) / 2.61 Å(15 Å) / **28.9 Å(20 Å)** / 0 Å(25 Å)。
  - 也就是说 **20 Å 那个解找到了另一个摆法，相关值只差 0.004**。同一张图里"唯一解"还能有 14–24 个（n_unique_fits），15 Å 下第一名 0.8812、第二名 0.8777（差 0.0035，姿态不同）。
  - **固定 seed 还不够**：官方同一段话还要求先 `view initial`。实测没写 `view initial` 时，同一条命令、同一个 `seed 42`、同一个珠模型与同一条曲线，两次会话给出两套阶梯（0.8973→0.9122 与 0.8678→0.8812，唯一解 9–23 vs 14–24）——随机初始摆放被约束在"当前显示区域"里。加进脚本后两次运行逐位一致。
  - **结论口径**：报"最好的那个摆法 + 分数 + 还有几个分数接近的不同摆法"，**不许**把一个摆法当答案交出去。

## A1 — 案例 (Past Application)

**1. A5-05-1：一条 20.8 Å 的小蛋白曲线，两个靶子都嵌进去了**（源B，实跑）

- 输入：`processed/Tube-SAXS/A5-05-1/`（可信 IFT：Dmax 72.6 Å、Rg 20.77 Å，q 0.0567–0.2592）+ `models/A5.pdb`（232 残基/2 链、25.0 kDa、Shape Rg 17.4 Å）+ `models/denss.mrc`。
- 珠模型（本次代建）：GNOM(Rg 20.79, χ² 0.94, total estimate 0.613) → DAMMIF **Fast ×15**（χ² 1.37–1.97，Rg 全部 20.80 Å，Dmax 81–89 Å）→ DAMAVER（mean NSD **0.73**±0.29，**2 个簇**）→ 取 `-global-damfilt` 共识模型（**669 个 bead**，dummy atom radius 2.30 Å）。
- CIFSUP：`--method=NSD` 下 **REGRID 0.875**（=SUPCOMB fast 口径）/ BACKBONE 1.141 / ALL 2.202 / SHELL 2.202。几何复核：CA 到最近 bead 的距离中位数 3.35 Å、最大 24.6 Å、**65.5% 在 8 Å 内**（这个比例随 damfilt↔damaver 与珠模型系综变，是复核不是判据）→ 主体落在珠球格子里，末端/环有外伸。
- fitmap（`view initial` + `search 200 seed 42`）：最高分在 25 Å，**correlation 0.8820 / cam 0.8046**，21 个唯一解；R 阶梯 0.8678→0.8812→0.8782→0.8820；**姿态散布最大 28.9 Å**（20 Å 那个解，分数只差 0.004）。同一对文件两次独立运行逐位一致。
- 结论口径：珠模型分支"NSD 0.875（REGRID 口径）"，电子云分支"correlation ~0.91，但至少存在两个分数接近的不同摆法"。

**2. 喂错 q 窗口，GNOM 会把"可疑解"给你**（源B，实跑对照）

- 同一条 A5-05-1 曲线、同一个 Dmax=72.58 Å，只换 q 起点：用**整条曲线**（idx_min=0，含低 q 上翘）→ GNOM χ² **338**、DISCRP 18.28（理想 0.7）、总估计 0.4663「**a SUSPICIOUS solution**」；用流水线**可信窗口**（idx_min=129, q≥0.0567）→ χ² **0.94**、总估计 0.613「**a REASONABLE solution**」。
- 结论：**代建珠模型前必须先读上游的表**（`tables/ift_summary.json` 的 `chosen` + `trusted`，取其 `idx_min`/`qmax`/`dmax`/`rg`）。这也是 `embed-model.py` 默认干的事；样品本身没通过闸门时它只给 `warning`，不替你下结论。

**3. ATSAS 4 的 `datgnom` 没有 Dmax 参数**（源B，实跑）

- 命令行 `datgnom` 的帮助里只有 `-r/--rg`（**Rg，必填**），没有 Dmax 选项：喂 `-r 20.77` 会自动定出 **Dmax 55.6 Å**，而同一批数据流水线的 P(r) 是 **72.6 Å**。Dmax 差 30% 会直接改变珠模型的大小。
- 处方：**用 RAWAPI 的 `gnom(profile, dmax, rg=…)`**（Dmax 是你给的，q 范围也是你给的），别用 `datgnom` 兜。ATSAS 4 的 `dammif` 只吃 GNOM `.out`，RAWAPI 会顺手把 `.out` 写出来。

**4. 图不能混坐标系；ChimeraX 的 `--nogui` 存不了图**（源B，实跑）

- 第一版图把"珠模型 + 电子云 + 电子云里 fit 好的模型"画在一张图上 → 看到"模型戳出珠球一大截"的假象。原因：珠模型与 DENSS 图各自居中在各自原点，相对取向无约束。**两个靶子两张图**。
- 用 ChimeraX `--nogui` 渲图直接失败：`LimitationError: Unable to save images because OpenGL rendering is not available`（脚本不报错，只是没有 png）。改用 **PyMOL**：`/Applications/PyMOL.app/Contents/bin/python3.10` 里 `pymol.finish_launching(['pymol','-cq'])` → `cmd.ray` → `cmd.png`（珠球画 `spheres`，电子云画 `isosurface` 并给 `transparency`，否则珠球把蛋白全遮住）。

**5. 同一个模型在 6 个稀释序列样品上的 NSD 从 0.775 到 4.426**（源B，实跑）

- 同一条 `A5.pdb`、同一套流程，只换样品：可信的三个样品 **0.875(A5-05-1) / 0.775(A5-05-2) / 1.931(A5-05-6)**；
  未过闸门的三个样品 1.231 / 1.973 / **4.426**（A5-05-5 的 P(r) Rg 已经 41.8 Å，是大颗粒那一类）。
- 电子云分支：三个有 `.mrc` 的样品相关值都在 0.89–0.91，**姿态散布都在 26–29 Å**。
- 结论：NSD 读作"**这条曲线给出的包络里能不能塞进这个模型**"，读不出"模型对不对"；同一模型跨样品的差异
  主要来自各样品自己的 P(r)/包络（样品是否通过了上游闸门先决定可不可信）。完整表见
  `references/bead-and-density-embedding-parameters.md` §8。

## A2 — 触发场景 (Future Trigger)

**用户会在什么情境下遇到这类问题**

- 手上有一条高分辨模型（晶体/CryoEM/AlphaFold/设计模型）和一个从头算重建（DAMMIF/DAMMIN 珠模型或 DENSS 电子云），要把模型"摆进去"看一眼。
- 已经叠好了，想知道 NSD/correlation 这个数怎么读、算好还是不好。
- `fitmap` 结果里 `correlation` 是 None，或者只有一个 `overlap`。
- 同一张电子云里跑出好几个分数几乎一样的摆法，不知道报哪个。
- 想要一张"模型在珠模型里/在电子云里"的图，发现 ChimeraX 无头模式存不出 png。
- 珠模型还没建（样品目录里只有 `.mrc` 和曲线），需要先把珠模型建出来再嵌。

**语言信号**

- 「把这个 PDB 叠到珠模型上」「把 model 嵌进 bead model / 电子云里」
- 「NSD 0.87 算好吗」「NSD 和 DAMAVER 的 NSD 是一回事吗」
- 「fitmap 没给 correlation」「correlation 0.91 算配上了吗」
- 「为什么有两个差不多的解」「电子云里模型摆哪儿都一样吗」
- 「ChimeraX 报 OpenGL / 存图失败」
- 「A5.pdb 在 A5-05-1…6 里长什么样」

**与相邻 skill 的区别**

- 与 `fit-a-high-resolution-model-to-data`：那边是**用曲线判模型**（CRYSOL/PDB2SAS 直接拟合出 χ²），本 skill 是**用重建判摆放**（NSD / correlation）。文档给的方向是拟合优先：**两者冲突时以拟合为准，错的是重建**。
- 与 `evaluate-a-shape-reconstruction`：那边评"这批重建散不散"（七条判据、DAMAVER/DAMCLUST/AMBIMETER）；本 skill 的输入就是它判过的那份重建，**判据 6（模型 Rg/Dmax 对上 P(r)）不通过时先回那边，别急着嵌**。
- 与两条 end-to-end 流水线：它们把曲线一路做到 DENSS 图 + DAMMIF/DAMAVER 珠模型；本 skill 从它们的产物出发（只在珠模型缺失时补建）。
- 与去卷积/系综类方法：本 skill 只做刚体叠合；柔性/多构象体系要系综方法（EOM/SASSIE/BilboMD），超出范围。

## E — 执行步骤 (Execution)

1. **确认两个靶子在不在、是不是同一批产物。** 看样品目录：`models/denss.mrc`（电子云）、`models/*damfilt*|*damaver*`（已有珠模型）、`profiles/03_subtracted/subtracted.dat` + `tables/ift_summary.json`（代建珠模型用）。
   完成标准：能说出"电子云有/没有、珠模型有/没有、代建时用哪条可信 IFT"。判停点：电子云没有且不打算建 → 只做珠模型分支，并把"没有电子云"写进结果（本次 A5-05-3/4/5 就是这样）。
2. **读上游决定（只有代建珠模型时才需要）。** 从 `tables/ift_summary.json` 取 `chosen` 那条 run 的 `idx_min/qmax/dmax/rg` 与 `trusted`。
   完成标准：能报出用哪个 q 窗口、Dmax/Rg 是多少、是不是可信。判停点：`trusted=false` → 照建但把 `warning` 写进结果，并把 NSD 定性为"仅指示"。
3. **（代建时）GNOM → DAMMIF ×N → DAMAVER。** `gnom(profile, dmax, rg=…)` 走 RAWAPI（**不要**用 `datgnom` 代替，它没有 Dmax 参数）；DAMMIF 默认 **15** 个（Fast 试、Slow 出终稿），DAMAVER 平均后**取 `-global-damfilt`**（滤过平均=最可能模型）。
   完成标准：报出 GNOM 的 χ²/总估计、DAMMIF 各模型的 χ²/Rg/Dmax、DAMAVER 的 mean NSD±sd 与簇数、共识模型的 bead 数与 bead 半径。判停点：DAMMIF 的 Rg 与 P(r) 的 Rg 差很多、或 beads 数明显对不上体积 → 先回 `evaluate-a-shape-reconstruction`。
4. **分支 1：CIFSUP 叠珠模型。** `cifsup --method=NSD --selection=REGRID -o <out>.cif <珠模型> <模型>`；**NSD 从输出文件的头部读**（`grep '^score'`，CIFSUP 没有 stdout）。
   完成标准：拿到 `score`，并附上四个 selection 的对照（ALL/BACKBONE/REGRID/SHELL）与所用 selection/beads 参数。判停点：NSD > 1（系统性不同）时**不要**就此说"模型不对"，先做第 5 步的几何复核，再回 `fit-a-high-resolution-model-to-data` 判模型本身。
5. **几何复核（一分钟，值得做）。** 数一下模型 CA 到最近 bead 的距离分布（中位数、8 Å 内的比例）。实跑参考：A5-05-1 中位数 2.2 Å、94% 在 8 Å 内。
   完成标准：能说出"模型是落在珠球格子里，还是有一截在外面"。判停点：大面积在外面 → 先怀疑珠模型系综（第 3 步）而不是模型。
6. **分支 2：fitmap 嵌电子云。** `fitmap #2 in #1 resolution <R> metric correlation search <N> seed <M> logFits <csv> listFits true`，然后 `save` 出被移动后的模型。跑一条 **R 阶梯**（10/15/20/25 Å），每个 R 都取 CSV 里最好的那一行。
   完成标准：每个 R 都有 `correlation / correlation_about_mean / overlap / average_map_value / n_unique_fits / top3`。判停点：**没有 `resolution` 就会拿到 correlation=None**；`search 0` 只是局部优化，结果取决于初始位置——两者都不算做完了。
7. **报"姿态散布"，不是报一个摆法。** 用各 R 下最好摆法的 CA 坐标两两算 RMSD（都在电子云坐标系里）。
   完成标准：给出"最大散布 X Å + 对应的 R + 分数差"。判停点：散布 > 5 Å 且分数接近（实测 28.9 Å / 差 0.004）→ 结论必须写成"至少两个分数相当的不同摆法"，并说明 SAXS 包络本身不唯一。
8. **出图（两张）。** 珠模型坐标系一张（模型 + 珠球）、电子云坐标系一张（模型 + isosurface），用 PyMOL 渲（ChimeraX `--nogui` 存不了图）。珠球记得给透明度，否则蛋白全被遮住。
   完成标准：两张 png 里模型都在包络内/内缘，且没有把两个坐标系画进同一张图。
9. **落盘并交付。** 每个样品一个 `embed/`：`embed_results.json`（含 `input/warning/bead_model/beads_fit/density_fit/figure`）、叠好的 PDB/CIF、fitmap CSV、两张图；再写一份人看的 `README.md`。
   完成标准：别人只拿这些文件就能复述"用的哪条 q 窗口、哪个 selection、哪个 resolution、分数是多少、有没有第二个解"。

## B — 边界 (Boundary)

**不要用的场景**

- 想回答"模型配不配数据" → 走 `fit-a-high-resolution-model-to-data`（CRYSOL/PDB2SAS）。本 skill 的分数全是几何/摆放分数，**没有任何一个是拟合优度**。
- 想判"这个重建能不能用" → 走 `evaluate-a-shape-reconstruction`；本 skill 只是把模型放进去。
- 想把坐标**精修**进图里（real-space refinement、MDFF、EM-fit 优化） → 不是本 skill；这里只有刚体叠合。
- 柔性/多构象体系、需要同时解释多个组分 → 系综方法，超出范围。
- 珠模型/电子云不存在又不想建 → 明确写"该分支缺失"，别拿另一分支的分数顶替。

**实跑里踩过、且源里明确警告过的失败模式**

- **CIFSUP 没有运行时输出**（源A 手册原文）：`score`（NSD）只写在输出文件的 `_atsas_superposition` 头里（PDB 输出是 `REMARK 265`）。不看文件就以为"程序没给分"。
- **不给 `resolution` 就没有 correlation**（源A fitmap 文档原文）：atoms-in-map 模式只有 `average_map_value`，CSV 里 correlation 是 None。
- **fitmap 是局部优化**（源A 文档原文）：不 `search` 就是"从当前位置附近找"，初始位置决定结果；要可复现还得固定 `seed`（官方要求配 `view initial`）。
- **报 NSD 不带 selection/beads 参数**：同一对模型，REGRID 0.875 与 ALL 2.202 是一个量级差别；`--beads` 也改 NSD（实测默认 2000 → 0.744，`--beads=1200` → 0.686）。
- **把 DAMAVER 的 NSD 阈值当嵌入阈值**：DAMAVER 的 mean NSD 是"这批 DAMMIF 模型彼此像不像"，与本 skill 的"模型 vs 珠模型"不是同一件事，别互相套。
- **两个坐标系画一张图**：珠模型与 DENSS 图各自居中在各自原点、相对取向无约束，混画会得到假的"戳出去"。
- **ChimeraX `--nogui` 存图失败**：`Unable to save images because OpenGL rendering is not available`（不会让脚本退出，只会静默没有 png）。用 PyMOL 渲。
- **喂整条曲线给 GNOM**：低 q 上翘会让 GNOM 给出 χ² 数百、"SUSPICIOUS"的 P(r)，珠模型跟着歪（见 A1-2）。

**版本与依赖**

- **CIFSUP 需要 ATSAS ≥ 4**（它是 SUPCOMB 的后继；本机 `/Applications/ATSAS-4.1.4-1/bin/cifsup`）。旧版 ATSAS 只有 SUPCOMB，参数名不同（`--mode=slow|fast`、`--superposition=backbone|ALL`）。
- `--method=NSD` 才是 SUPCOMB 等价；CIFSUP 的默认方法其实是 **ICP**（实测 ICP 给 8–9 这种量级，与 NSD 不可比）。
- DAMMIF/DAMAVER/GNOM 来自 ATSAS；DENSS 图由上游流水线（RAW 内建 DENSS）产出。ChimeraX 1.9 的 fitmap 行为（`search`/`logFits`/CSV 列名）以本机实测为准。
- **RAWAPI 要 ATSAS 的 `bin` 目录**（它拿父目录当 ATSAS 变量）；直接跑 ATSAS 二进制要 `ATSAS=<安装根>`。

**材料盲点**

- 官方手册**没有给"NSD 多少算嵌入得好"的分级**，只给"→0 理想、>1 系统性不同"。本 skill 不编阈值。
- 官方手册**没有给"fitmap correlation 多少算配上了"的阈值**；correlation 随 resolution、图的性质（masked/unmasked、scale）变，本 skill 只报数并附 R 与姿态散布。
- DENSS 电子云**单模型没有 FSC**，读不出重建分辨率 → 用 R 阶梯 + 姿态散布代替，这是替代口径，不是分辨率测量。
- 引用要求：用 CIFSUP 替代 SUPCOMB 时引 SUPCOMB 原文（M. Kozin & D. Svergun (2001) *J Appl Cryst* 34, 33-41）；用 DENSS 图时引 T. D. Grant *Nature Methods* (2018) 15, 191-193；用 ChimeraX 时引其论文。

**参考文件**：CIFSUP/fitmap 的完整参数表、CSV 列名、RAWAPI 调用式、以及本次 6 个样品的实跑数字见
`references/bead-and-density-embedding-parameters.md`。可执行入口：`scripts/embed-model.py`（一条命令跑完两条分支）、`scripts/render-embed-figure.py`（PyMOL 出图）。
